# mcping website

The project website for [mcping](https://github.com/tanishworks/mcping) — a
minimal, monochrome (pure black / pure white) site built with **Vite +
React + TypeScript**.

- Live URL: https://tanishworks.github.io/mcping/
- Deployed to the `gh-pages` branch via
  [`.github/workflows/website.yml`](../.github/workflows/website.yml) (GitHub
  Pages) on every push to `main`.

## Quick start

```sh
cd website
npm install
npm run dev        # dev server (matches the /mcping/ base path too)
npm run build      # type-check + build + produce dist/404.html
npm run preview    # serve the production build locally
```

## Stack & structure

```
website/src/
├── fonts.css               @font-face rules pointing at local woff2 files
├── theme/
│   ├── theme.tsx           ALL color tokens (single source of truth) + useTheme()
│   └── theme.css           font stacks, ascii-reveal vars, token fallbacks
├── hooks/
│   ├── useFontsReady.ts    gates reveals until local fonts are loaded
│   └── useScrollSpy.ts     docs sidebar scroll-spy + slug/text helpers
├── components/
│   ├── SiteHeader.tsx      pill nav (sliding indicator), menu btn, repo icons
│   ├── GradientBackground.tsx  drifting gradient blobs + noise grain
│   ├── Markdown.tsx        custom react-markdown components (.md styling)
│   └── Icons.tsx           inline SVG icons (currentColor)
├── pages/
│   ├── Home.tsx            hero, install pill, feature cards, terminal sample
│   └── Docs.tsx            sidebar outline + rendered docs.md
├── content/docs.md         the actual docs content (rendered on /docs)
└── styles/global.css       all layout/component CSS
```

## Design system

All colors live in [`theme/theme.tsx`](src/theme/theme.tsx) as tokens like
`bg`, `fg`, `muted`, `hairline`, `gradientA…C`, `noise`, `shadow`, `scrim`.
Every component/stylesheet consumes them through CSS variables
(`var(--bg)`, `var(--hairline)` …) generated by `ThemeProvider`; nothing is
ever colored inline. The scheme follows the OS `prefers-color-scheme`
automatically (light and dark are both pure monochrome).

Typography hierarchy:

| Role   | Font               | Used for                                    |
| ------ | ------------------ | ------------------------------------------- |
| pixel  | Press Start 2P     | hero title, card index labels, sidebar label |
| mono   | JetBrains Mono     | pill nav, terminals, code, docs outline      |
| body   | Inter (variable)   | prose, card copy                             |

Fonts are self-hosted woff2 files in `src/assets/fonts/` (no Google Fonts
network hits) with `font-display: block`, and page reveals are gated behind
`useFontsReady()` + `document.fonts.ready` so ascii-reveal never animates in a
fallback typeface.

The decode animations come from [`ascii-reveal`](https://github.com/quanhoangindex/ascii-reveal)
(`AsciiReveal`, `AsciiSkeleton`) — used for the hero title, install pill,
feature cards and the terminal sample.

## Deployment

`npm run build` output is uploaded to the `gh-pages` branch by the automated
workflow on every push to `main`. To trigger a deploy manually, dispatch the
`website` workflow from GitHub.
